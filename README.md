# Bank Loan Portfolio Dashboard | Tableau

## Project Overview
The Bank Loan Portfolio Dashboard is an interactive data visualization project developed using Tableau to analyze bank loan disbursement, repayment performance, loan status, and default risk from 2015 to 2023. It provides insights into lending trends, regional performance, loan purposes, credit scores, and repayment behavior to support data-driven decision-making.

## Key Performance Indicators (KPIs)
- **Total Disbursed:** ₹47.0M
- **Default Rate:** 10.0%
- **Delinquency Rate:** 10.0%
- **Repayment Rate:** 103%

## Dashboard Features

### 1. Disbursement Trend by Year
Analyzes annual loan disbursement trends from 2016 to 2023 to identify changes in lending activity over time.

### 2. Loan Status Distribution
Displays the distribution of loans across four categories:
- Fully Paid
- Paid Off
- Active
- Default

### 3. Loan Purpose Analysis
Compares loan amounts across different purposes, including Services, Trade, Home Loan, and Agriculture, to identify major lending categories.

### 4. Regional Disbursement vs. Default Risk
Compares loan disbursement amounts and default risk across regions to identify regional lending patterns and potential credit-risk areas.

### 5. Default Rate by Credit Score
Analyzes default rates across different borrower credit-score groups:
- Below 550
- 550–649
- 650–749
- 750 and above

### 6. Repayment Behaviour by EMI Type
Compares repayment behavior between Monthly EMI and Quarterly EMI categories to understand differences in repayment status.

## Interactive Filters
The dashboard includes interactive filters for:
- Year (2015–2023)
- Branch Performance
- Loan Purpose
- Region

These filters allow users to explore specific segments of the loan portfolio and compare performance across different categories.

- Understand annual loan disbursement trends.
- Analyze the distribution of loans by status.
- Identify loan purposes contributing the highest disbursement amounts.
- Compare regional lending activity and default risk.
- Evaluate default rates across credit-score categories.

- Support data-driven lending and credit-risk monitoring.

## Conclusion
This project demonstrates the use of Tableau to transform bank loan data into an interactive dashboard. It brings key lending and repayment metrics together in one view, helping users explore portfolio performance, identify patterns, and investigate potential credit-risk areas.
